# 선택 사항: Notion 회귀 목록

사용자가 Notion 기록을 요청하고 대상 데이터베이스가 정해진 경우 메인이 연결된 Notion 도구로 해당 데이터베이스의 속성을 읽는다. 프로젝트와 시나리오 ID로 기존 행을 먼저 찾는다. 행에는 기대 동작, 플랫폼, 시나리오 버전, 최근 검증한 빌드, 결과, 남은 확인 사항을 기록한다. 같은 빌드 재시도는 기존 행을 갱신하고 중복된 행이 여러 개면 자동 병합하지 않는다.

실행 가능한 경로의 원본은 프로젝트에 둔다. 다른 사람이 열 수 있는 산출물 링크나 사용자가 지정한 첨부본만 공유한다. 로컬 절대 경로·계정 정보·원본 캡처는 외부 전송 대상에서 제외한다. 연결이 없거나 게시에 실패하면 로컬 실행 결과와 게시 상태를 따로 보고한다.
